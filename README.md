# Fokus

Aplicação de timer para ajudar a manter o foco e organizar pausas durante os estudos, baseado no método pomodoro. O projeto foi desenvolvido com HTML, CSS e JavaScript, sem necessidade de instalação ou build.

## Acessar

O projeto está publicado no GitHub Pages:

**[Abrir o Fokus](https://bandiniraul.github.io/Projeto-Fokus/)**

## Funcionalidades

- Timer de foco de 25 minutos.
- Timer de descanso curto de 5 minutos.
- Timer de descanso longo de 15 minutos.
- Controles para começar e pausar a contagem.
- Efeitos sonoros ao começar, pausar e ao finalizar o tempo.
- Opção para ativar ou desativar a música de fundo.
- Interface adaptável a diferentes tamanhos de tela.

## Como usar

1. Abra o [Fokus](https://bandiniraul.github.io/Projeto-Fokus/).
2. Escolha **Foco**, **Descanso curto** ou **Descanso longo**.
3. Clique em **Começar** para iniciar a contagem.
4. Clique em **Pausar** para interrompê-la; clique novamente em **Começar** para continuar.
5. Ative o controle **Música** se quiser ouvir a música de fundo.

## Executar localmente

Clone o repositório e abra `index.html` no navegador. Como é um projeto estático, não é necessário instalar dependências ou executar um servidor de desenvolvimento.

```bash
git clone https://github.com/BandiniRaul/Projeto-Fokus.git
```

Em seguida, abra o arquivo `index.html` dentro da pasta clonada.
